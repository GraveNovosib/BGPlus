# BGPlus 4 — now public property.

![BGPlus 4](images.png)

[Русский](README.md) | English | [Polski](README.pl.md)

Well, anons. Viktor went so overboard protecting his stuff that we got curious about how deep the rabbit hole went.

Spoiler: not that deep. We picked at the protection, dug through the contents, and pulled out the modules.

**What’s being released is the mod files in their native game formats.**

The release contains **3,085 files: 882 from BC and 2,203 from AC.**

What’s inside:

- `bc/Core` — the mod core, configs, missions, resources, and scripts.
- `bc/New_Trucks` — new trucks and related data.
- `ac/English_dialog` — English dialogue and resources.
- The rest — races, missions, game modes, starting locations, wear, interface changes, and other goodies.

The formats are native too: `.ltf`, `.pkqt`, `.sch`, `.class`, `.jar`, `.dds`, and plenty more. Some containers are still encrypted, but there’s already plenty to dig into.

**For those who can read:** the files are organized by edition, module, and original path. The contents of `BgPlus/4/tmp/Scripts.jar/` belong INSIDE `Data/scripts.jar`. Some mods conflict, so don’t slap everything on at once and then scream that the game is dead.

**EXE patches are on hold for now.** For fairly obvious reasons. This release contains no `.exe` or `.dll` files. All in good time.

This is a research dump, not a ready-made one-click build. Nobody guarantees that every file has been tested or that everything will work straight away.

**HACKERS, REVERSERS, MODDERS — YOU’RE UP.**

Study it, experiment, and make your own modifications. Want to understand how it all works? The documentation is included.

Vitya tried to build a fortress and ended up with a public reverse-engineering club.
